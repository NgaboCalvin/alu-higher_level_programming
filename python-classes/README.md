# Python Classes - OOP Project

## Overview

This project covers Object Oriented Programming (OOP) concepts in Python, specifically focusing on the `Square` class implementation. The goal is to understand and implement various OOP concepts such as:

- Classes and Objects
- Private instance attributes
- Property getters and setters
- Data encapsulation
- Public methods

## Tasks

### 0. My first square
Write an empty class Square that defines a square.

### 1. Square with size
Add a private instance attribute `size` to the Square class.

### 2. Size validation
Implement validation for the `size` attribute:
- Must be an integer (raise TypeError otherwise)
- Must be >= 0 (raise ValueError otherwise)

### 3. Area of a square
Add a public method `area()` that returns the current square area.

### 4. Access and update private attribute
Implement property getters and setters for the private `size` attribute with validation.

### 5. Printing a square
Add a public method `my_print()` that prints the square using the `#` character.

### 6. Coordinates of a square
Add position functionality to the Square class:
- Private instance attribute `position` (tuple of 2 positive integers)
- Property getter and setter for position with validation
- Use position to print the square with proper offset

## Requirements

- All files must start with `#!/usr/bin/python3`
- All files must be executable
- All modules, classes, and methods must have documentation (docstrings)
- Code should follow pycodestyle (version 2.7.*) standards
- No external imports allowed (you are not allowed to import any module)
