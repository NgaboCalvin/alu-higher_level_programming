# Python - More Data Structures: Set, Dictionary

Working with sets and dictionaries, `lambda`, `map`, and a Roman numeral
converter for technical interview practice.

## Requirements

- Python 3 (tested with python3 / 3.8.5 on Ubuntu 20.04 LTS)
- pycodestyle 2.7.*
- Every file starts with `#!/usr/bin/python3`, ends with a newline, and is
  executable

## Tasks

| File | Description |
| --- | --- |
| `0-square_matrix_simple.py` | Square every value of a matrix into a new matrix |
| `1-search_replace.py` | Replace all occurrences of an element in a new list |
| `2-uniq_add.py` | Add all unique integers in a list |
| `3-common_elements.py` | Return a set of common elements in two sets |
| `4-only_diff_elements.py` | Return a set of elements present in only one set |
| `5-number_keys.py` | Return the number of keys in a dictionary |
| `6-print_sorted_dictionary.py` | Print a dictionary ordered by keys |
| `7-update_dictionary.py` | Replace or add a key/value in a dictionary |
| `8-simple_delete.py` | Delete a key from a dictionary if it exists |
| `9-multiply_by_2.py` | Return a new dictionary with all values multiplied by 2 |
| `10-best_score.py` | Return the key with the biggest integer value |
| `11-multiply_list_map.py` | Multiply list values using `map`, max 3 lines |
| `12-roman_to_int.py` | Convert a Roman numeral to an integer |

## Constraint notes

- No imports are used in any task.
- No loops are used in `11-multiply_list_map.py` (only `map` with a `lambda`).
- `12-roman_to_int.py` returns `0` when the input is not a string (including
  `None`).
