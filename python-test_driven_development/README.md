# Python - Test-driven development

Python projects focused on writing tests first using doctest and unittest.

## Files

- `0-add_integer.py` — add two integers.
- `2-matrix_divided.py` — divide all elements of a matrix.
- `3-say_my_name.py` — print a name.
- `4-print_square.py` — print a square.
- `5-text_indentation.py` — print text with indentation.
- `6-max_integer.py` — find the max integer in a list.
- `tests/` — doctest and unittest files.
